## Campaign theme

The hero is the **10% Spring Sale on all whole spices, through May 31** —
the active promo per CLAUDE.md §10. Three sub-anchors layer on top:

1. **Akshaya Tritiya** (Tuesday May 19) — auspicious day for pantry-refresh
   and new beginnings. Bonus: it falls on a Tuesday, which is our weekly
   sambar-masala grinding day at the back of the shop. The "fresh on the
   auspicious day itself" angle is the single best line we have this month.
2. **Indian wedding season peak** — bulk masala + gift baskets, both shops
   carrying extra inventory.
3. **Memorial Day weekend** (May 23–25) — peripheral but real for a desi
   audience: tandoori spice + Kashmiri chili + garam masala for the
   backyard grill.

The email anchors on Akshaya Tritiya + the sale, sends **Tue May 12 10 AM**
(7-day lead). The Reel lands on hand-grinding cardamom (high motion-
potential subject). The flyer is the 10% Spring Sale — type-led, two-
location stacked, rangoli accent.

## Schema + integration notes

All asset JSON files include a `$comment` field naming which agent
produced them and which CLAUDE.md sections informed the conventions.
The `api/src/jobs/dispatch-campaign.ts` runtime consumes these files
as the contract for what shape Meta Graph API / Resend / FAL.AI
schedulers receive. Run a dry-run with:

```
cd api
npm run dispatch:aditis-spice-depot
```

This writes a `dispatch-log.json` next to this README — re-runs are
idempotent (slots already scheduled get skipped).

## Why this campaign in the repo (not just in Supabase)

Two reasons:
1. **Demonstrates the team end-to-end** — Saturday meeting (May 16, with
   Ravi Marri) + onboarding demos for future South Asian SMB clients.
2. **Versioning** — campaigns evolve month over month; git history
   records which hook moved, when we adjusted the CTA, who tightened
   the cardamom caption.

Once `api/` is fully wired and Supabase is hooked up, monthly campaigns
become DB rows in `campaigns` + `campaign_assets`; these JSON files are
the shape those rows must match.
