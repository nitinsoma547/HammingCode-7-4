## Campaign theme

Three concurrent hooks driving the month:

1. **Mother's Day** (May 10) — single-day brunch peak.
2. **AAPI Heritage Month** — four weekly vendor features.
3. **Memorial Day weekend** (May 23–25) — the broader anchor: grill
   class, graduation party last-call, three-day-weekend hours.

The email anchors on Memorial Day (broader, multi-CTA), sent **May 14
Tuesday 10 AM** — 11 days lead. The Reel slot lands on the AAPI feature.
The flyer is the Memorial Day grill class — the single asset that drives
the most reservations this month.

## What the operator still needs to do

Generative work is done; some fields need the operator's input to ship:

- **Confirm vendor count + names** for the AAPI feature weeks (assumed 4)
- **Confirm grill class price** ($65 placeholder)
- **Confirm Mother's Day pre-fixe pricing**
- **Pick + tag photos** for each post in `monthly_intakes.photo_urls`
  — most posts have `needs_image_from_intake: true`
- **Fill `operator_fillins`** in social-calendar.json (vendor names,
  dish names, reviewer first name + quote)
- **Render the flyer locally if you want a fresh PNG** — `bash flyer/render.sh`
  (already rendered once; re-run after any spec edits)
- **Run brand-voice-reviewer over the assets** before scheduling — it
  reads the brand_profile.do_not_say list and flags violations
- **Operator approval before Outstand/Resend/FAL.AI send**

## Schema notes

All asset JSON files include a `$comment` field naming which agent
produced them and which CLAUDE.md sections informed the conventions.
The api/src/services/campaign-generator runtime will read these same
files as the contract for what shape Outstand / Resend / FAL.AI
schedulers consume.

## Why this is in the repo (not just in Supabase)

Two reasons:
1. **Demonstrates the team end-to-end** — Saturday meeting + onboarding
   demos for future clients.
2. **Versioning** — campaigns evolve month over month and we want git
   history (who changed what hook, when we adjusted the CTA).

Once `api/` is built and Supabase is wired, monthly campaigns become
DB rows in `campaigns` + `campaign_assets`; these JSON files are the
shape those rows match.
