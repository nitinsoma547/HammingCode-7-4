# .mcp.json — MCP servers wired for this repo

Project-level MCP server config that Claude Code picks up automatically
when you open this repo. Servers listed here expose tools the agents
(and the main session) can call directly during dev-time.

## Servers

### `meta` — Facebook Pages + Instagram Graph API

Wraps Meta's content publishing endpoints. Used by Claude Code at
dev-time to call IG/FB post tools when prototyping. **Production
posting runs through `api/src/services/meta/`** — that's the code we
own and which the monthly campaign cron will use.

**Package:** [oliverames/meta-mcp-server](https://github.com/oliverames/meta-mcp-server)
(200+ tools covering Pages, IG, Threads, Ads, Insights). If the npm
package name has drifted, swap to one of the alternatives:

- [mcpware/instagram-mcp](https://github.com/mcpware/instagram-mcp) — IG-only, lean
- [HagaiHen/facebook-mcp-server](https://github.com/hagaihen/facebook-mcp-server) — FB-only
- [mikusnuz/meta-mcp](https://github.com/mikusnuz/meta-mcp) — IG + Threads, 57 tools, Graph API v25.0

**Required env (in `.env`):**
- `META_PAGE_ACCESS_TOKEN` — long-lived Page Access Token
- `META_FB_PAGE_ID` — numeric Facebook Page ID
- `META_IG_USER_ID` — numeric Instagram Business account ID
- `META_GRAPH_API_VERSION` — pin to `v21.0` unless deliberately bumping

See `api/src/services/meta/META_SETUP.md` for the full App Review +
token-generation walkthrough.

**Gate:** the MCP server CAN run without Meta App Review approval, but
it can only post to **test Pages owned by app admins** until Advanced
Access is granted. Real client Pages need the review (4–6 weeks per
Meta's May 2026 docs).
